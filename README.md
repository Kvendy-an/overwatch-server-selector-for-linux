# Overwatch Server Selector for Linux

A native Linux app to avoid selected Overwatch servers. Choose a region or individual servers, check their ping, and keep your blocks updated automatically.

## Get started

1. Download the AppImage from [GitHub Releases](https://github.com/Kvendy-an/overwatch-server-selector-for-linux/releases), mark it executable, and open it.
2. Click **Enable firewall control** if prompted.
3. Choose the servers to **block**, click **Apply selection**, and authenticate before launching Overwatch. Leave at least one server available.

Click the **signal-bars icon** to refresh ping. To remove your blocks, click **Unblock all**.

Requires x86_64 Linux with glibc 2.39+, systemd, nftables, PolicyKit, and Python 3.10+. The AppImage bundles the GUI runtime. Ping readings require the host `ping` command.

Blocks persist after closing the app and affect all apps on your account using those IP ranges. A preferred server is not guaranteed. If a match cannot connect, use **Unblock all**. Ping readings may differ from in-game latency.
