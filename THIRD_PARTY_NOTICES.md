# Dropship server data

`data/servers.json` is an unmodified snapshot of the server feed published by stowmyy/dropship:

- Repository: https://github.com/stowmyy/dropship
- Feed: https://stowmyy.github.io/dropship/ips.json
- Server definitions: https://github.com/stowmyy/dropship/blob/main/scripts/ips/overwatch.js
- Retrieved: October 11, 2026
- License: GNU General Public License v3.0, preserved in `data/DROPSHIP-LICENSE`

The notices included in that JSON snapshot are upstream feed data and are not executed. The app reads only server records. No Dropship application code is included in this project.
