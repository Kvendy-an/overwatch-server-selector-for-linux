## Changes

- Enable OpenGL rendering by default. This fixes the severe UI lag reproduced on an RTX 4090 with KDE Wayland using the previous software-rendering default.
- Show server ping beside each server, with background checks and a signal-bars button to refresh readings.
- Bundle the signal icon directly so it does not depend on desktop icon themes.
- Remove the slogan, repeated warnings, and address-range counts for a simpler interface.

## Install or upgrade

Download **Overwatch-Server-Selector-0.2.0-x86_64.AppImage**, mark it executable, and launch it as your normal desktop user. Close the old app before opening the new build. Existing saved blocks and the installed helper are retained.

Requires x86_64 Linux with glibc 2.39+ and a Wayland or X11 desktop. The GUI runtime is bundled. Firewall control requires host nftables, PolicyKit, systemd, and Python 3.10+.

For ping readings, install the host `ping` command (`iputils` on Fedora/Arch; `iputils-ping` on Ubuntu/Debian). ICMP readings estimate latency to the feed's probe targets and may differ from in-game latency. Some targets do not answer ICMP; these show **No reply**. Saved blocks show **Blocked**. Preview mode sends no probes.

If OpenGL fails on a particular system, launch with `GSK_RENDERER=cairo` for the software fallback.

## Verification

The assets include SHA-256 checksums, the matching source archive, detailed launch instructions, and a validation report. Run `sha256sum -c SHA256SUMS` after downloading both the AppImage and source archive.

31 unit tests, GTK preview and latency smoke tests, bundled SVG loading, and isolated nftables integration checks passed. Scrolling reached roughly 120 FPS on the tested RTX 4090/KDE Wayland session. AMD and Intel hardware were not retested for this build. Host firewall changes, reboot restoration, and Overwatch matchmaking were not tested during this release validation.
